Installer le jeu

Choisis ton appareil. Les versions PC et Mac se mettent à jour toutes seules.

Sur Windows

  1. Télécharge NeonBreaker.exe avec le bouton.
  2. Lance-le. Si un message bleu « Windows a protégé votre ordinateur » apparaît, clique sur Informations complémentaires puis Exécuter quand même.
  3. C'est tout : pas d'installation, et le jeu se met à jour tout seul.

Le message bleu apparaît parce que le jeu n'est pas signé (ça coûte cher). Le fichier est vérifié à chaque mise à jour.

Sur Mac

  1. Télécharge la version de ton Mac. Pas sûr ? Menu Pomme > À propos de ce Mac : « Puce Apple » (M1, M2…) ou « Intel ».
  2. Ouvre le .zip, puis glisse NEON BREAKER dans le dossier Applications.
  3. La première fois : clic droit sur l'app > Ouvrir, puis Ouvrir encore. Ensuite, un double-clic suffit.

Sur iPhone et iPad

  1. Ouvre cette page dans Safari, puis touche Jouer maintenant.
  2. Touche le bouton Partager (le carré avec une flèche).
  3. Choisis Sur l'écran d'accueil : le jeu devient une app, en plein écran.

Le jeu se joue en vertical, au doigt : glisse en bas pour bouger la raquette, touche le terrain pour lancer la balle.

Sur Android

  1. Ouvre cette page dans Chrome, puis touche Jouer maintenant.
  2. Ouvre le menu ⋮ en haut à droite.
